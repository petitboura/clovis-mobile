# Installer Clovis (version complète)

Cette page t'explique ce que fait cette version de Clovis, pourquoi elle
demande des autorisations un peu spéciales, et comment l'installer en
confiance.

## C'est quoi cette version ?

Il existe deux versions de l'app Clovis :

- La version **Play Store** : la version simple, installée normalement
  depuis le Play Store.
- Cette version, **complète** : elle ajoute une capacité supplémentaire
  (lire ce qui s'affiche à l'écran dans tes autres apps, pour t'aider
  directement dedans). Le Play Store n'autorise pas ce genre de capacité
  pour une app comme Clovis, donc cette version se télécharge directement
  ici, en dehors du Play Store.

## Pourquoi elle demande l'accessibilité ?

Android appelle ça un "service d'accessibilité" : c'est la même technologie
que les lecteurs d'écran pour les personnes malvoyantes. Clovis s'en sert
pour voir ce qui est affiché à l'écran quand tu ouvres une app, afin de
pouvoir t'aider directement dedans plus tard. Pour l'instant, Clovis **lit
seulement** : il ne clique sur rien et ne modifie rien à ta place. Tu peux
désactiver cette autorisation à tout moment dans les réglages de ton
téléphone.

## Comment installer en confiance

1. Télécharge le fichier `.apk` depuis la
   [page des versions](https://github.com/petitboura/clovis-mobile/releases)
   du dépôt officiel `petitboura/clovis-mobile` — ne télécharge ce fichier
   nulle part ailleurs.
2. Ton téléphone va probablement te prévenir qu'il s'agit d'une app venant
   "d'une source inconnue" : c'est normal et attendu, puisque cette version
   n'est pas sur le Play Store. Autorise l'installation uniquement pour ce
   fichier précis.
3. Une fois installée, connecte-toi avec ton compte étudiant habituel.
4. Pour les mises à jour suivantes : l'app te préviendra elle-même dans une
   bannière quand une nouvelle version est disponible, avec un bouton pour
   la télécharger. Pas besoin de revenir sur cette page à chaque fois.

## Une question, un doute ?

Si un fichier `.apk` de Clovis circule ailleurs que sur cette page ou sur
[github.com/petitboura/clovis-mobile/releases](https://github.com/petitboura/clovis-mobile/releases),
ne l'installe pas et signale-le.
